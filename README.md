# Mapper

В приложение добавлен AutoMapper 12.0.1, подключённый как сервис через AddAutoMapper в Program.cs. Настроен профиль AppMappingProfile, в котором есть правила ForMember и Ignore. При регистрации данные с формы приходят в RegisterDto и превращаются в User через _mapper.Map. Список пользователей на странице «Пользователи» (только для Admin) берётся из БД методом ProjectTo<UserDto>, поэтому хэш пароля в запрос не попадает.
